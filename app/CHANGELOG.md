# Changelog

## 0.1.0

First public release. Papermark is a desktop Markdown editor:

- File mode opens a single Markdown file, folder mode browses and edits a
  whole folder of documents.
- The AI assistant rewrites the selection or writes at the cursor from
  your instruction, using your own OpenAI, Anthropic or Mistral key.
- Documents can be exported to and re-imported from an archive, and
  Markdown files and folders can be opened with Papermark from the file
  manager.
