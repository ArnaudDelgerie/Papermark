# Papermark

Papermark is a desktop Markdown editor that runs under
[TFSAppHub](https://github.com/ArnaudDelgerie/TFSAppHub). It has a file mode and
a folder mode, an AI assistant, and archive export and import. The editor is
built on [Milkdown](https://milkdown.dev)'s Crepe editor.

## Install

```console
tfsapp-hub install github:ArnaudDelgerie/Papermark
```

See the [TFSAppHub README](https://github.com/ArnaudDelgerie/TFSAppHub#install)
for how to get `tfsapp-hub`.
